# ソリティア・アトリエ

PC・スマートフォン向けのブラウザ版クロンダイクです。

## 起動

`dist/index.html` をブラウザで開くか、`dist` の内容を静的Webサーバーに配置してください。外部サービス・ライブラリ・ビルドは不要です。ローカルファイルで開く場合、ブラウザによっては画像や進行の保存が制限されます。

## 操作・ルール

- 1枚めくり／3枚めくり、山札は何度でも巡回可能。
- カードを選び、移動先をクリック／タップ。ドラッグでも移動できます。
- 選択カードをもう一度押すと、可能な場合に組札へ送ります。
- 表向きの並びをまとめて移動可能。空列はKのみ。
- 組札は同じスートをA〜Kの順に集めます。組札から場札へ戻せます。
- 最大100手の取り消し、合法手のヒント、勝利判定。
- Tab・Enter・Spaceで操作、Escで選択解除、Ctrl/Command+Zで取り消し。
- ゲーム進行は端末のlocalStorage、カード画像はIndexedDBへ保存。外部送信は行いません。端末・ブラウザ間の同期はありません。
- 時間はプレイ開始後から計測し、別タブ・ダイアログ表示中は停止します。取り消しでも時間は巻き戻りません。
- 配り方は無作為で、必ず解ける配札を保証しません。ヒントもクリアを保証しません。

## カード画像の変更

画面右上の「カードの画像」で変更できます。裏面1枚、表面は52枚を個別または複数まとめて読み込めます。PNG/JPEG/WebP、1枚5MBまで。推奨比率は5:7です。保存時は長辺1000px以下へ縮小します。

一括読込名：S_A.png、S_02.png〜S_10.png、S_J.png、S_Q.png、S_K.png。S/H/C/D＝スペード/ハート/クラブ/ダイヤ。拡張子はjpg/jpeg/webpも利用可能です。拡張子とスート・絵札の英字は大文字小文字を問いません。

差し替えた表面には識別用の数字とスートを上部へ重ね、画像全体を表示します。裏面は枠を埋めるために中央でトリミングされます。

初期画像自体を編集する場合は `dist/assets/cards/` の52個のSVGと `dist/assets/back.png` を変更します。PNG等を初期表面にする場合は `dist/app.js` の `src` にある拡張子を変更してください。

## 初期画像の制作

表面52枚は `scripts/generate-cards.py` で生成したSVGです。数字・スートの正確さと小画面の可読性を優先しています。

裏面は組み込みimage_genで生成したオリジナル画像です。プロンプト要約：平面・縦5:7、紺色と控えめな金色、幾何学的な天体装飾、中央に羅針盤と星、180度対称の構成、文字や数字なし、遠近感・外部背景なし。

## 構成・検証

- `dist/engine.js`：DOMに依存しないルール処理。
- `dist/app.js`：操作・描画・保存・画像設定。
- `dist/style.css`：PC/スマートフォン向けレスポンシブ表示。
- `node scripts/test-rules.cjs`：初期配札、移動制約、山札巡回、勝利判定、保存状態、ランダム合法手の整合性を検証。

この環境で実際のブラウザ描画・スマートフォン実機のQAは未実施です。
