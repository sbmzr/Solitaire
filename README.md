# ソリティア・アトリエ

PC・スマートフォン向けのブラウザ版クロンダイクです。

## 起動

`dist/index.html` をブラウザで開くか、`dist` の内容を静的Webサーバーに配置してください。外部サービス・ライブラリ・ビルドは不要です。ローカルファイルで開く場合、ブラウザによっては画像や進行の保存が制限されます。

## Netlifyで公開する

リポジトリ直下の `netlify.toml` に公開先フォルダを設定しています。ビルドやパッケージのインストールは不要です。

### GitHubと連携する場合

1. Netlifyで既存のGitリポジトリからプロジェクトを作成し、GitHubの `sbmzr/Solitaire` を選択します。
2. 次の設定でデプロイします。公開フォルダは `netlify.toml` から読み込まれます。

| 項目 | 設定 |
| --- | --- |
| Branch to deploy | `main` |
| Base directory | 空欄（リポジトリ直下） |
| Build command | 空欄（ビルド不要） |
| Publish directory | `dist` |

以後は `main` の更新に合わせて自動デプロイできます。

### 手動でアップロードする場合

1. GitHubの「Code → Download ZIP」でダウンロードし、ZIPを解凍します。
2. 解凍先の **`dist` フォルダ**をNetlifyの手動デプロイ欄へドラッグ＆ドロップします。
3. 発行されたURLを開いてプレイします。

アップロードするフォルダの直下に `index.html`、`app.js`、`engine.js`、`style.css`、`assets/` があることを確認してください。リポジトリ全体のフォルダではなく、`dist` を指定します。手動デプロイの更新時も、最新の `dist` を再度アップロードしてください。

ゲーム進行と変更したカード画像はURLごとにブラウザへ保存されます。以前の公開URLからNetlifyのURLへは自動で引き継がれません。

参考：[Netlifyの設定ファイル](https://docs.netlify.com/build/configure-builds/file-based-configuration/) / [手動デプロイ](https://docs.netlify.com/deploy/create-deploys/)

## 操作・ルール

- 1枚めくり／3枚めくり、山札は何度でも巡回可能。
- カードを選び、移動先をクリック／タップ。ドラッグでも移動できます。
- 選択カードをもう一度押すと、可能な場合に組札へ送ります。
- 表向きの並びをまとめて移動可能。空列はKのみ。
- 組札は同じスートをA〜Kの順に集めます。組札から場札へ戻せます。
- 最大100手の取り消し、合法手のヒント、勝利判定。
- Tab・Enter・Spaceで操作、Escで選択解除、Ctrl/Command+Zで取り消し。
- ゲーム進行は端末のlocalStorage、カード画像はIndexedDBへ保存。外部送信は行いません。端末・ブラウザ間の同期はありません。
- 時間はプレイ開始後から計測し、別タブ・ダイアログ表示中は停止します。取り消しでも時間は巻き戻りません。
- 配り方は無作為で、必ず解ける配札を保証しません。ヒントもクリアを保証しません。

## イカサマモード

画面上部の「通常モード」「イカサマモード」ボタンで切り替えます。ゲーム進行・時間・取り消し履歴はモード別に保存し、前回のモードで再開します。既存の通常モードの保存データも読み込めます。「新しいゲーム」は選択中のモードだけを配り直します。

| 特殊機能 | 上限 | 操作・効果 |
| --- | --- | --- |
| ポケットに入れる | 同時に3枚まで | ボタンを押して、場札の表向きカードかめくり札の一番上を1枚選び保管します。空いた枠は何度でも使えます。 |
| カードを入れ替え | 3回 | ボタンを押して、同じ対象範囲の2枚を順に選び、位置を交換します。組札は対象外です。 |
| ジョーカーを追加 | 2枚 | ボタンを押して場札の列を選び、末尾に万能札を追加します。色・数字にかかわらず重ねられ、上にも任意のカードを置けます。空列にも置けます。 |

- 特殊機能とポケットへの出し入れはそれぞれ1手として数え、「戻す」でカード・保管状態・残り回数を復元します。「選択を解除」またはEscで対象選択を中止できます。
- ポケットは任意の1枚を選び、通常の配置ルールに従って場札か組札へ取り出せます。タップ・ドラッグの両方に対応します。保管中の通常カードは達成枚数に含みません。
- ポケットへの保管・入れ替えで並びが崩れた場合、その部分はまとめて動かせません。末尾から1枚ずつ動かして整えてください。
- ジョーカーもポケットに保管して再利用できます。組札には置けません。
- 通常カード52枚を組札に送ればクリアです。追加したジョーカーは場札やポケットなどに残っていても構いません。
- 「1枚／3枚めくり」は両モードで選択可能。カード画像の設定は共通です。ジョーカーは専用表示で、画像差し替えの対象外です。

### 旧「破壊」モードの保存データ

旧データは読み込み時に自動移行します。破壊済みカード（ジョーカーを含む）はポケットへ復元します。組札が破壊済みの数字を飛ばして積まれていた場合は、欠番より上のカードを裏向きで山札の上へ戻します。52枚・追加ジョーカー・手数・経過時間・入れ替え／ジョーカーの残り回数を保ち、取り消し履歴も同じルールで移行します。再保存後は旧バージョンとの互換性はありません。

## 設定画面

画面右上の「設定」に、カードサイズ・カード画像・遊び方をまとめています。「ゲームに戻る」、右上の×、Escで盤面へ戻れます。設定画面を開いている間はプレイ時間が停止します。

- カードサイズは80〜160%を10%刻みで調整でき、その場で盤面に反映します。「標準サイズに戻す」で100%に戻ります。
- サイズは通常／イカサマモードで共通です。この端末・ブラウザに保存し、再読み込み後も維持します。進行や取り消し履歴は変わりません。
- 小さい画面では最小幅28pxを確保します。拡大して画面に収まらない場合は盤面だけが横スクロールします。タッチ操作ではカードの間の余白をスワイプできます。カードを選んでからスクロールし、移動先をタップして操作することもできます。
- 遊び方・操作方法は設定画面内で開けます。

## カード画像の変更

画面右上の「設定」→「カードの画像」で変更できます。裏面1枚、表面は52枚を個別または複数まとめて読み込めます。PNG/JPEG/WebP、1枚5MBまで。推奨比率は5:7です。保存時は長辺1000px以下へ縮小します。

一括読込名：S_A.png、S_02.png〜S_10.png、S_J.png、S_Q.png、S_K.png。S/H/C/D＝スペード/ハート/クラブ/ダイヤ。拡張子はjpg/jpeg/webpも利用可能です。拡張子とスート・絵札の英字は大文字小文字を問いません。

差し替えた表面には識別用の数字とスートを上部へ重ね、画像全体を表示します。裏面は枠を埋めるために中央でトリミングされます。

初期画像自体を編集する場合は `dist/assets/cards/` の52個のSVGと `dist/assets/back.png` を変更します。表面SVGを編集したら `python scripts/bundle-cards.py` で `dist/card-faces.js` も更新してください。PNG等の表面画像は設定画面から読み込めます。

## 初期画像の制作

表面52枚は `scripts/generate-cards.py` で生成したSVGです。数字・スートの正確さと小画面の可読性を優先しています。A〜10は右上・左下のスートを省き、中央のスートと左上・右下の数字を残します。J・Q・Kの図柄は維持しています。生成時には表面の一括データ `dist/card-faces.js` も更新します。

裏面は組み込みimage_genで生成したオリジナル画像です。プロンプト要約：平面・縦5:7、紺色と控えめな金色、幾何学的な天体装飾、中央に羅針盤と星、180度対称の構成、文字や数字なし、遠近感・外部背景なし。

## 表面表示の待ち時間対策

- デフォルト52枚のSVGを `dist/card-faces.js` で一度に読み込み、盤面ではSVG要素を直接描画します。カードをめくった時点の個別画像リクエスト・画像デコード待ちをなくします。
- SVGのひな型は一度だけ解析し、以降の描画で再利用します。画面全体を再描画しても、デフォルト表面は画像読み込みを待ちません。
- 差し替え画像はIndexedDBから取得後にデコードを済ませてから利用します。表示用画像が準備できるまではデフォルトの表面を表示し、白い面だけになることを防ぎます。
- 初回にサイト本体・裏面画像・保存画像を読み込む時間自体は残ります。

## 構成・検証

- `dist/engine.js`：DOMに依存しないルール処理。
- `dist/app.js`：操作・描画・保存・画像設定。
- `dist/style.css`：PC/スマートフォン向けレスポンシブ表示。
- `node scripts/test-cheats.cjs`：ポケットの容量・取り出し・再利用、旧データ移行、残り回数、ジョーカー、クリア判定、保存データの整合性を検証。
- `node scripts/test-card-assets.cjs`：52枚の表面と一括データの一致、A〜10の角スート削除、J・Q・Kの角スートを検証。
- `node scripts/test-rules.cjs`：初期配札、移動制約、山札巡回、勝利判定、保存状態、ランダム合法手の整合性を検証。

ヘッドレスChromiumでPC幅1280px・スマートフォン幅390pxのクリック／タッチ操作、PCのドラッグ操作、特殊機能、取り消し、モード別保存、再読み込みを確認済みです。スマートフォン実機でのQAは未実施です。
